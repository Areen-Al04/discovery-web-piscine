# Discovery Web Piscine 

## About This Project

This project is part of the Discovery Web Piscine. I learned basic Linux commands,Git, and GitHub.

## Why Git Makes Development Easier

Git protects my code by saving versions of my projects. If I make a mistake, I can go back to an earlier version.

Git also keeps a history of my changes. I can see what changed, when, and who changed it. I saw this myself when I used 'git log'.

Git makes teamwork easier because many people can work on the same project and combine their changes.

## Commands I Learned

- `pwd` : shows the current directory
- `ls` : lists files and folders
- `cd` : changes the directory
- `mkdir` : creates a directory
- `touch` : creates a file
- `cat` : shows the content of a file
- `git status` : shows the state of the repository
- `git add` : adds changes to the staging area
- `git commit` : saves changes in the history
- `git log` : shows the history of commits
- `git push` : sends commits to GitHub
